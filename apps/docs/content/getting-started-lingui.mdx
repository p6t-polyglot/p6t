# Getting Started

To get started with p6t, paste this into the AI assistant of your choice (Opencode, Claude Code, Cursor, etc.):

```txt
I'd like to internationalize my React app with p6t and Lingui.

1. Let's define the UX for our users. What languages are available to them and how do they select them?
2. Since Lingui is integrated with a compile step, we need to set it up with our build system. Check https://lingui.dev/ for options.
3. Let's define the languages that we want to support to begin with. We can always add more later
    All selected languages should be configured through ./i18n.json
4. Set up our LocaleContext and LocaleProvider to manage the current locale in our app.
5. Wrap our strings in <Trans> components and add descriptions for translators.
6. Run p6t translate to sync our strings with the translation service and get translations for our supported languages.
7. Test our app in different locales to ensure the translations are working correctly.

For each of the above steps, please make suggestions based on your available knowledge and best practices and
ask me for any additional information or confirmation. Also make sure you allow me to ask for additional context
or clarification at any point.

Consider the actual best practices.

For example for the languages available to users, we might consider SEO for public pages and saving things to a user profile in case we have a user account.
For Lingui, we consider how we make sure that we have a workflow that ensures new developers and agents automatically
integrate it well, meaning every new string comes with a description.
```
