p6t (polyglot) automates the localization (l10n) workflow so your CD pipeline stays continuous. Translate every new string automatically — using your own LLM API key, with no external service required.

```diff
 // react-intl
 intl.formatMessage({
-  defaultMessage: 'Welcome back.',
+  defaultMessage: 'Welcome back, {name}!',
   description: 'Dashboard heading shown after login.',
-})
+}, { name: user.name })
```

```bash
$ p6t translate
✓ 1 new string translated  →  es, fr, de
✓ 1 orphaned string removed  →  es, fr, de
```
