p6t (polyglot) automates the localization (l10n) workflow, so that your CD pipeline stays continuous. Wrap your strings in `<fbt>` components and ship every feature in every language—automatically.

```diff
 function WelcomeHeading({ user }) {
   return (
-    <fbt desc="welcome heading">Welcome back.</fbt>
+    <fbt desc="welcome heading">
+      Welcome back, <fbt:param name="name">{user.name}</fbt:param>!
+    </fbt>
   );
 }
```

```bash
$ p6t translate
✓ 1 new string translated  →  es, fr, de
✓ 1 orphaned string removed  →  es, fr, de
```
